# Ecomotive IoT - Data Engineering

## Project Overview
End-to-end IoT Data Engineering project developed using Databricks.

## Architecture
Medallion Architecture:
- Bronze: Data ingestion.
- Silver: Data cleansing and transformation.
- Gold: Dimensional modeling and integration.

## Technologies
- Databricks
- Apache Spark
- PySpark
- SQL
- Delta Lake
- Unity Catalog
- Auto Loader
- Databricks Workflows

## Data Quality
Implementation of validation rules, data deduplication and reconciliation controls.

## Orchestration
Automated pipeline execution using Databricks Workflows.
